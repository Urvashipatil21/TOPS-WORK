SESSION 6: ENCAPSULATION VS ABSTRACTION
Task 5: Explanation with Daily Social Media Examples (WhatsApp & Instagram)
================================================================================

1. WHAT IS ENCAPSULATION?
--------------------------------------------------------------------------------
Definition:
Encapsulation is the process of binding data (variables) and the methods (functions)
that operate on that data into a single unit (class), while hiding direct access 
to the internal state using access modifiers like 'private' and 'protected'.

Daily Social Media Example (WhatsApp / Instagram Profile):
- On WhatsApp or Instagram, your account settings contain sensitive data like 
  your Phone Number, Email, and Password.
- These variables are marked 'private'.
- Nobody can directly open your account and change your password in the database.
- Instead, WhatsApp provides a public interface: "Edit Profile" or "Change Password" 
  screen (like getter and setter methods).
- It verifies your old credentials before updating. 
- That is Encapsulation: DATA HIDING & SECURITY.

--------------------------------------------------------------------------------
2. WHAT IS ABSTRACTION?
--------------------------------------------------------------------------------
Definition:
Abstraction is the concept of showing only the essential features of an object 
to the outside world while hiding all complex background implementation details.

Daily Social Media Example (Instagram Upload / WhatsApp Voice Call):
- When you tap the "Share / Post" button on Instagram or tap "Voice Call" on WhatsApp:
  - What you see: Just a simple button.
  - What happens behind the scenes (Hidden):
    - Audio/Video compression algorithms.
    - End-to-end encryption protocols.
    - WebRTC / socket connections to the other person's IP address.
    - Routing packets through cloud data centers.
- You don't need to know socket programming to talk to your friend. 
- That is Abstraction: COMPLEXITY HIDING & SIMPLIFICATION.

--------------------------------------------------------------------------------
3. KEY DIFFERENCES SUMMARY
--------------------------------------------------------------------------------
Feature               Encapsulation                         Abstraction
--------------------------------------------------------------------------------
Focus                 "How data is protected/stored"        "What an object does"
Target                Data Hiding (Security)                Complexity Hiding (Interface)
Mechanism             Access modifiers (private, public,    Abstract classes, Pure virtual
                      protected) and Getters/Setters        functions, Interfaces
Social Media Analogy  Locking your private chat data &      The "Send" button hiding
                      only allowing access via PIN/TouchID  complex network protocols
